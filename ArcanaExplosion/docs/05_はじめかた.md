## 🎮 まずは動かしてみよう

### ステップ1：フォルダをオフラインで使えるようにする ⚠️ 最初にやって

Googleドライブのファイルは、そのままだと「クラウドにあるだけ」でPCに実体がありません。
その状態だとゲームが動かないことがあります。

1. エクスプローラーで `ArcanaExplosion` フォルダを右クリック
2. 「**オフラインで使用できるようにする**」を選ぶ
   （Googleドライブのメニューの中にあります）
3. 緑のチェック ✅ が付くまで待つ

> 💡 これをやると、フォルダの中身が自分のPCにダウンロードされます。

---

### ステップ2：Python を入れる

ゲームは Python という言語で作られているので、それが必要です。

1. https://www.python.org/downloads/ を開く
2. 「Download Python」の黄色いボタンを押す
3. ダウンロードしたファイルを実行する
4. ⚠️ **インストール画面の一番下にある「Add python.exe to PATH」に必ずチェックを入れる**
   （これを忘れると動きません。忘れたら入れ直せばOK）
5. 「Install Now」を押す

---

### ステップ3：Flask を入れる

ゲームがブラウザで動くために必要な部品です。1回入れれば以降は不要。

1. スタートメニューで `cmd` と打って「コマンド プロンプト」を開く
2. 黒い画面に、下の行をコピペして Enter

```
py -m pip install flask
```

3. 最後に `Successfully installed flask...` みたいに出れば成功🎉

> ❓ `py` が見つからないと言われたら、代わりにこっちを試してください
> ```
> python -m pip install flask
> ```
> それでもダメなら、ステップ2の「Add python.exe to PATH」のチェックを忘れている可能性が高いです。

---

### ステップ4：起動する

`ArcanaExplosion` フォルダの中の **`ひとりで遊ぶ.bat` をダブルクリック**！

> 💡 スマホや他のPCからも繋ぎたいときは **`みんなで遊ぶ（スマホもOK）.bat`** のほう。
> どちらで起動しても、CPU対戦もLAN対戦も遊べます。

ブラウザが自動で開いてゲームが始まります🎴
うまくいったら、まず1回遊んでみてください。

**終わるとき**：黒い画面で `Ctrl` + `C` を押すか、その窓を閉じてください。

## 🛠️ ファイルを直してみる

### 一番かんたん：`balance.json`

ゲームの数字が全部入っているファイルです。**Pythonが分からなくても触れます。**

例えば `"trainer_hp": 200` を `100` に変えると、試合が半分の速さで終わります。

直したら **ゲームを起動し直す**と反映されます（開きっぱなしだと反映されません）。

### 直したあとの確認

数字を変えたら、こう打つとCPU同士が400回対戦して結果を教えてくれます。

```
py -3 simulate.py --games 400
```

- 先攻勝率が **45〜55%** なら健全
- 平均ターン数は **30〜40** くらいが目安

「強くしすぎたかな？」と思ったらこれで確かめられます📊

## 🚨 守ってほしいルール（大事！）

### ルール1：同じファイルを同時に触らない ⚠️ 一番大事

Googleドライブは、**2人が同時に同じファイルを保存すると、片方の作業が消えます。**
これは元に戻せません。

だから作業を始める前に、**オグさんに「今からこのファイル触るね」と伝えてください。**

例：
> 「今日は `web/style.css` と `balance.json` を触ります」

### ルール2：触らないフォルダ

| フォルダ | 理由 |
|---|---|
| `.git` | バックアップの仕組みが入っています。壊すと履歴が消えます |
| `_backups` | 過去のバックアップzipです。消さないで |
| `__pycache__` | Pythonが勝手に作るゴミです。消してもOKだけど触らなくていい |

### ルール3：文字コードは UTF-8

ファイルを編集するときは **UTF-8** で保存してください。
**Windowsのメモ帳は使わないほうが安全**です（勝手に文字コードを変えることがある）。

おすすめは **VS Code**（無料）：https://code.visualstudio.com/

## ❓ よくあるトラブル

| 症状 | 対処 |
|---|---|
| `py` は認識されていません | Pythonのインストールで「Add python.exe to PATH」を忘れている。入れ直す |
| `No module named flask` | ステップ3をやっていない。`py -m pip install flask` |
| ブラウザが真っ白 | アドレスが `http://localhost:5000/` になっているか確認 |
| 黒い画面がすぐ消える | エラーが出ている。文字を読むか、画面を撮ってオグさんに見せる |
| ファイルが見つからないと言われる | ステップ1の「オフラインで使用できるようにする」をやっていない |
| 変えたのに反映されない | ゲームを起動し直す（黒い画面を閉じてbatを再実行） |
