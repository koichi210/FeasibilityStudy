# 🎴 おぐそーのカードゲーム

リアルのトランプ3箱で遊べるオリジナルカードゲームの、PC版。
いまは **PoC（試作）** の段階で、ブラウザで CPU と対戦できる。

> 🤝 **オグさん＋共同開発者の共同開発プロジェクト**（AIアシスタントのClaudeも参加）。
> ルールも数値もまだ確定していないので、意見・アイデアは大歓迎。
> 初めての人は 👉 [docs/05_はじめかた（共同開発者へ）.md](docs/05_はじめかた（共同開発者へ）.md)

---

## 🚀 遊びかた

**`ゲーム起動.bat` をダブルクリック** するだけ。ブラウザが自動で開く。

閉じるときは、黒いコマンド画面で `Ctrl + C`。

> コマンドから起動したい場合は `py -3 run.py`

### 操作

| やりたいこと | 操作 |
|---|---|
| ⚔️ 攻撃する | 「攻撃」ボタンを押す |
| 🔄 交代する | 自分のベンチのカードをクリック |
| 🎒 アイテムを使う | 下の手札のカードをクリック |
| ⏭️ 手番を終える | 「ターン終了」ボタンを押す |

金色の枠がついているカードが「いまクリックできるカード」。

## 🌐 LAN対戦（人間同士）

同じネットワークにいる2人で対戦できる。**相手に手札は見えない。**

### 手順

1️⃣ **サーバー役のPC**で `LAN対戦用に起動.bat` をダブルクリック
　→ 黒い画面に `http://192.168.x.x:5000/` のようなURLが出る

2️⃣ **2人ともそのURLをブラウザで開く**（サーバー役の人も同じURLでOK）

3️⃣ 片方が **「🌐 LAN対戦」→「🏠 部屋を作る」**
　→ **4文字の合言葉**（例：`K7QM`）が表示される

4️⃣ もう片方が **「🌐 LAN対戦」→「🔎 部屋に入る」**
　→ 一覧に相手の部屋が出るのでクリック（合言葉を直接入力してもOK）

5️⃣ 2人そろったら自動でゲーム開始🎴

### 注意

- ⚠️ `https` ではなく **`http`**。LAN内なので証明書は不要
- ⚠️ 初回はWindowsファイアウォールの確認が出るので「**アクセスを許可する**」を選ぶ
- 💡 ブラウザを再読み込みしても**席は維持される**（同じ席で戻れる）
- 💡 相手の操作は1〜2秒で自動的に画面へ反映される

## 📱 スマホ・タブレットから遊ぶ

同じWi-Fiに繋がっていれば、**スマホのブラウザからも遊べる**。
`LAN対戦用に起動.bat` で起動して、表示されたURLをスマホで開くだけ。

**PC vs スマホ** の対戦もできる📱⚔️💻

| | |
|---|---|
| 📶 注意 | スマホが**モバイル通信ではなくWi-Fi**に繋がっていること |
| 🔢 使うIP | 複数出たときは **Wi-Fi のほう**を選ぶ |
| 👆 操作の違い | スマホは**カードをタップすると詳細が開き、ボタンで実行**する2段階。指が当たっただけで交代してしまう事故を防ぐため |

> 💡 PC版とスマホ版で**ファイルは共通**。画面の広さで見た目が切り替わる作りなので、
> 機能を追加すれば自動的に両方へ反映される（2回作る必要はない）。

## 💾 バックアップ・バージョン管理

フォルダを日付付きでコピーしていく方式より、こっちのほうが楽で確実。
**2段構え** にしてある。

### 1️⃣ `保存.bat` — 作業のセーブポイントを作る（git）

作業がひと区切りついたらダブルクリックする。
「何をした？」と聞かれるので一言書く（空欄でもOK）。

その時点のファイル全部が記録される。**あとから何度でもその状態に戻せる。**
差分だけ記録するので、何百回保存してもフォルダは重くならない。

### 2️⃣ `履歴.bat` — 保存の履歴を見る／戻しかたを確認する

いつ何を保存したかの一覧と、昔の状態に戻すコマンドが表示される。

### 3️⃣ `バックアップ.bat` — zipで丸ごと退避

`_backups\card-game_20260902-2249.zip` のようなファイルが1つできる。

git が壊れたときの保険。大きな変更をする前や、他の人に渡す前に押しておくと安心。
直近20件だけ自動で残る（古いものは自動削除）。

> 💭 **なぜフォルダコピーじゃないの？**
> フォルダコピーだと、Google Drive が中身のファイルを全部同期し直すので重い。
> zip なら1ファイルなので軽いし、フォルダ一覧も散らからない。

### ⚠️ 共同開発するときの注意

このプロジェクトは Google ドライブの共有フォルダにある。

- **2人が同時に同じファイルを編集しない**こと（同期がぶつかって片方が消える）
- 本格的に複数人で開発するなら、GitHub などにリポジトリを置くのがおすすめ
  （git はもう入っているので、リモートを追加するだけで移行できる）

## 🔧 開発メモ

```bash
py -3 run.py                    # ゲーム起動
py -3 run.py --lan              # LANに公開して起動
py -3 simulate.py --games 400   # CPU同士で400戦してバランス確認
py -3 tools\gen_cardlist.py     # カードリストmdを再生成
```

- **Python 3.9 以上**。`python` ではなく **`py -3`** を使うこと
  （`python` は Windows ストアのダミーに繋がってしまう環境のため）
- 依存ライブラリは **Flask のみ**（インストール済み）
- ソース・JSON・md はすべて **UTF-8**
- ⚠️ **`tools\*.ps1` を編集したら、必ず「UTF-8(BOM付き)」で保存すること**。
  Windows PowerShell 5.1 は BOM無しUTF-8 のスクリプトを日本語Windowsの文字コードとして
  読んでしまい、日本語コメントがスクリプトの構文を壊す。
  （VS Codeなら右下の「UTF-8」→「エンコード付きで保存」→「UTF-8 with BOM」）
- git は単体インストールされておらず、**GitHub Desktop 同梱のもの**を使っている。
  `tools\_git.ps1` が自動で探すので普段は意識しなくてよい
- バランスを変えたら `simulate.py` で影響を確認する習慣をつけると事故が減る
