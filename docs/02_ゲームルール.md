# 📖 ゲームルール（PoC 実装版）

このドキュメントは **いまコードで実際に動いているルール** を記述したもの。

原案には数値が決まっていない部分がいくつかあったので、
「まず遊べる状態にする」ことを優先して仮の値を入れている。
仮決めした箇所には 🟡 マークを付けてあるので、実際に遊んで違和感があればそこから疑うこと。

数値はすべて [`balance.json`](../balance.json) に外出ししてある。**調整はコードではなくJSONを触る。**

---

## ⚙️ ゲームオプション

画面右上の「⚙️ オプション」から、遊ぶ前にルールを切り替えられます。

| オプション | オフにすると | 使いどころ |
|---|---|---|
| ⚔️ **モンスターの技** | J・Q・K・A の特殊能力が発動しなくなる | **はじめての人向け。** 攻撃力と防御力だけの勝負になるのでルールが単純 |
| 👹 **魔王（♠A）** | ♠A を出しても魔王が降臨しない | 魔王の一発逆転が強すぎると感じるとき |

- 「モンスターの技」をオフにすると、**魔王も自動的にオフ**になります（魔王は ♠A の技なので）
- 設定を変えると**新しいゲームが始まります**
- 選んだ設定は `user_options.json` に保存され、**次回起動時も引き継がれます**

> 💭 リアルのトランプで遊ぶときにも「今日は技なしで」という遊び方ができます。

## 🏁 勝利条件

**相手のトレーナーHPを0にしたら勝ち。**

- トレーナーHP：**200**
- 200手番（両者合計）を超えた場合は、残りHPが多いほうの勝ち 🟡

## 🏟️ 場の構成

プレイヤー1人につき、場に出せるモンスターは **最大3枚**。

| 場所 | 枚数 | 役割 |
|---|---|---|
| ⚔️ バトル場 | 1枚 | 攻撃・防御を行う。攻撃されるのもここ。**相手にも中身が見える** |
| 🛡️ ベンチ | 3枚 | 直接は戦わない。バフ・補助効果でバトル場を助ける。**相手には伏せ札（何体いるかだけ見える）** |

### 🙈 相手に見えない情報

**ベンチ・モンスター手札・アイテム手札の中身**は相手に伏せられている。
画面だけでなく **ログにも出ない**。相手のログには
「ベンチにモンスターを1体配置」のように**枚数だけ**が伝わる。

> 💡 伏せる処理はサーバー側（`Game.view`）でやっている。相手向けのログ行は
> 送信する前に落としているので、通信を覗かれても中身は分からない。

アイテムは **使った瞬間に公開**される（何を使ったかはログに出る）。

### 🃏 モンスター手札と配置

モンスター手札は、**アイテム手札と同じルールで増える**。

1. バトル場が空いたら、**ベンチから一番元気なモンスターが自動で繰り上がる**（これは常に自動・即座）
2. **自分のターン開始時に、モンスターデッキから1枚だけモンスター手札に自動で補充**される（手札上限7枚）
3. モンスター手札のカードは、**プレイヤーが好きなタイミングで空いている枠に配置**する（回数制限なし・攻撃/交代/アイテムの権利は消費しない）
4. ベンチも山札も空なら、バトル場は空のままになる（→ 相手に直接攻撃される）

> 🟡 モンスターが倒れた／退場した直後に自動で手札が増えるわけではない。
> 空いた枠は次の自分のターン開始まで空きっぱなしになることもある
> （アイテム手札と同じ「毎ターン1枚」ペース）。

> 🟡 **ゲーム開始時だけは例外**：両者が同時に配置しないと、先攻だけ「配置→攻撃」を
> 済ませてしまい、後攻はまだ1度もモンスター手札に触れられずバトル場が空＝
> 直接攻撃され放題という不公平が起きる。そのため初期配置だけは山札から
> 両者同時に自動で場へ出す（モンスター手札を経由しない）。

## 🔄 ターンの流れ

自分の番が来ると、以下が自動で処理される。

### 1️⃣ ターン開始処理（自動）

1. 行動権のリセット（攻撃1回・交代1回・アイテム1枚が使えるようになる）
2. **疲労カウントを1減らす**
3. 毒・呪いの継続ダメージを受ける
4. ターン開始時の技が発動（♥J ヒーリングナイトなど）
5. **魔王の残りターンを1減らす**（0になったら消滅）
6. **バトル場が空いていればベンチから繰り上げ**
7. **モンスターを1枚引く**（手札上限7枚）
8. **アイテムを1枚引く**（手札上限5枚）

### 2️⃣ メインフェイズ（プレイヤーの操作）

1ターンにできることは以下。**順番は自由**、それぞれ独立してカウントされる。

| 行動 | 回数 | 内容 | 画面での操作 |
|---|---|---|---|
| ⚔️ 攻撃 | 1回 | バトル場のモンスターで攻撃する。疲労中は不可 | **バトル場の自分のカードをクリック** |
| 🔄 交代 | 1回 | バトル場とベンチを入れ替える。**交代してもその後に攻撃できる** 🟡 | ベンチのカードをクリック |
| 🎒 アイテム | 1枚 | 手札のアイテムを1枚使う | アイテム手札をクリック |
| 🃏 配置 | 制限なし | モンスター手札を場に出す | モンスター手札をクリック（バトル場が空ならそこへ、あとはベンチに左詰め） |

### 3️⃣ ターン終了

「ターン終了」を押すと相手の番になる。

> 💡 ボタンの色が状況を教えてくれる。
> 🔴 **赤**＝まだ攻撃できる（押すのはもったいない） /
> 🟢 **緑**＝攻撃は済んだ /
> 🟡 **金色に点滅**＝もうできる事がない。
> 赤いまま押そうとすると確認が出る。

## 😴 疲労と強制退場 — このゲームの核

```
攻撃した  →  疲労カウント = 2
              ↓  自分のターン開始時に -1
次の自分のターン開始時  →  疲労カウント = 1  →  攻撃できない ❌
              ↓  さらに次のターン開始時に -1
その次の自分のターン    →  疲労カウント = 0  →  攻撃できる ⭕
```

つまり **1体のモンスターは、自分の手番2回に1回しか攻撃できない**。

さらに **合計2回攻撃したら、HPが残っていても強制退場**（捨て札へ）。

> ⚠️ 強制退場ではトレーナーにダメージは入らない。自分から下がっただけなので。

### 疲労を回避する手段

- ♣J「気付け薬」（アイテム）… 疲労を即座に回復する
- ♠K「暴君」（モンスター）… そもそも疲労しない。ただし攻撃のたび自傷20

## ⌛ ベンチ置きっぱなしバフの期限

**場に置いておくだけで味方を支え続ける3枚**は、攻撃されない安全地帯から
永久に効果を出し続けられると強すぎるため、**ベンチにいられるのは3ターンまで**。

| カード | 効果 |
|---|---|
| ♥Q 聖女クイーン | ベンチにいる間、バトル場の防御+30 |
| ♣K 指揮官キング | ベンチにいる間、バトル場の攻撃+30 |
| ♥J ヒーリングナイト | 毎ターン、自分の場の全モンスターを回復 |

- 🟡 カウントは**ベンチにいる間だけ**進む（バトル場にいる間は減らない。魔王のカウントと逆）
- 期限が切れると、HPが残っていても**強制退場**（捨て札へ）
- 強制退場なので、トレーナーへのダメージは入らない
- バトル場に出したあと再びベンチに戻しても、**残りターン数はそのまま引き継がれる**（リセットされない）

## ⚔️ 戦闘とダメージ計算

### 基本式

```
ダメージ = 攻撃力 － 相手の防御力
```

- 🟡 **最低保証ダメージ 10**：計算結果が10未満でも、必ず10は通る。
  （これがないと、防御が高いカードが完全無敵になってしまうため）
- 🟡 **オーバーキル分は貫通しない**：HP20の相手に100ダメージを与えても、余剰80は消える。

### 🟡 モンスターのHP（原案で未定義だった部分）

原案には「HPはカードに書かない」とあったが、**何点で倒れるか**が決まっていなかった。

→ **全モンスター共通で HP 100** とした。

理由：

- リアルのトランプで遊ぶとき、カウンター管理が一番ラク（全員100スタートで統一）
- 防御力がそのまま「硬さ」になるので、弱いモンスターは自然にすぐ倒れる
- 防御力を「ダメージ軽減」と「体力」の両方に使うと、高数字が硬すぎて試合が終わらない

**計算例：**

| 攻撃側 | 防御側 | ダメージ | 何発で倒せるか |
|---|---|---:|---|
| ♦10（攻100） | 防御20 の相手 | 80 | 2発 |
| ♦10（攻100） | 防御80 の相手 | 20 | 5発 |
| ♠5（攻80） | 防御100 の相手 | 10（最低保証） | 10発 |

1体につき生涯2回しか攻撃できないので、**1体で相手1体を倒しきるのはかなり難しい**。
自然とカードが回る設計になっている。

## ❤️ トレーナーへのダメージ

トレーナーHPが削れるのは以下の3パターン。

| きっかけ | ダメージ |
|---|---|
| 🟡 自分のモンスターが**相手に倒された**とき | **30** |
| 🟡 自分のモンスターが**相手の毒で倒れた**とき | **30** |
| 🟡 自分のモンスターが**♠A 禁断の契約で葬られた**とき | **30**（＋使った側は自分に-50） |
| 相手のバトル場が空のときに**直接攻撃**したとき | **攻撃力そのまま** |
| カード固有の効果（♦K 破壊王、♠K 生贄の儀式など） | カード次第 |

> ⚠️ 呪い（魔剣の自傷）・反動・自爆など **自分のせいで倒れた場合はトレーナーダメージなし**。
> 毒は相手が仕掛けてくるものなので、毒で倒れた場合は「相手に倒された」扱いでカウントされる。
> ♠A 禁断の契約も「相手に葬られた」扱いなので撃破ダメージが入る。

## 🎒 アイテム

- アイテムデッキは **両プレイヤーで共有の1箱（52枚）** 🟡
- 毎ターン開始時に **1枚ドロー**、手札上限は **5枚** 🟡
- **1ターンに1枚まで**使用できる
- 装備系（武器・防具）は、**装備したモンスターが退場すると一緒に失われる**

強化値は控えめに設定してある（アイテムだけでは勝てないように）。
全52種の効果は [03_カードリスト.md](03_カードリスト.md) を参照。

## 👹 魔王

**♠A「魔王降臨」** をモンスターとして場に出した瞬間、魔王に変身する。

| 項目 | 値 |
|---|---|
| HP | 250 |
| 攻撃 | 150 |
| 防御 | 150 |
| 存在ターン | 3（自分のターン開始時に1減る） |

### 制約

- **魔王同士は攻撃できない** — 両者が魔王を出すと、お互い手出しできず膠着する 🟡
- **バトル場にいる間だけ**3ターンのカウントが減る。**ベンチにいる間は消滅しない**（カウントは止まったまま）
  → ベンチに温存すれば、消滅を気にせず出しっぱなしにできる
- カウントが0になると自動的に消滅する（捨て札へ）。消滅ではトレーナーダメージは入らない
- 魔王も疲労・2回攻撃退場のルールに従う

> 💭 「魔王同士は攻撃できない」は原案どおりに実装したが、
> 両者が魔王を出すと完全に手が止まるので、遊んでみて微妙なら見直したいポイント。

## ♻️ 山札切れ

- モンスターデッキが尽きたら、**自分の捨て札のモンスターをシャッフルして山札に戻す** 🟡
- アイテムデッキが尽きたら、**アイテムの捨て札をシャッフルして戻す** 🟡

デッキ切れによる敗北はない（試合が終わらなくなるのを防ぐため）。
