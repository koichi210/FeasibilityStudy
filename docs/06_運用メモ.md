# 🗂️ 運用メモ（バックアップ・バージョン管理・残件）

このプロジェクトをどう安全に運用するかのメモ。**主にオグさん向け。**
共同開発者は読まなくても作業できます（[05_はじめかた（共同開発者へ）.md](05_はじめかた（共同開発者へ）.md) を見てください）。

## 👥 開発体制

| 役割 | 担当 | やること |
|---|---|---|
| 🧒 共同開発者 | **実装メイン** | ゲームの中身（カード効果・バランス・見た目・遊びやすさ）。**gitは触らない** |
| 👨 オグさん | **基盤担当＋オブザーバー** | LAN対戦などの技術的な土台、開発環境、**セーブポイント作成（git）** |

ゲームの内容は「実際に遊ぶ人の感覚」がいちばん正しいので、共同開発者が主役。
オグさんは口を出しすぎず、通信・環境まわりを引き受ける、という分担。

触るファイルが自然に分かれるので、**同時編集の事故も起きにくくなる**という副次効果もある。

| | よく触るファイル |
|---|---|
| 🧒 共同開発者 | `web/`、`balance.json`、`engine/cards.py` |
| 👨 オグさん | `server/`、`run.py`、`tools/` |

### なぜ共同開発者にgitを触らせないのか

git は強力な分、操作を間違えると作業が消えるコマンドがあります
（`git reset --hard` など）。
**触らせないことで事故を構造的に防ぐ**、という判断です。

代わりにオグさんがこまめにセーブポイントを作ることで、
共同開発者が何をどう壊しても巻き戻せる状態を保ちます。
つまり **git は共同開発者を縛るものではなく、共同開発者を守る保険**です。

## ⚠️ 一番の危険：同時編集

**Googleドライブは、2人が同時に同じファイルを保存すると片方の変更が消えます。**
そして **gitでもこれは防げません**（gitに記録される前に消えるため）。

### 対策

1. 📢 **作業前に声をかける** … 「今から `web/app.js` 触るね」
2. 📁 **担当ファイルを分ける** … 例：共同開発者＝`web/`、オグさん＝`engine/`
3. 💾 **こまめにセーブポイントを作る** … 記録済みなら復元できる

> 💭 将来的にGitHubに移行すれば、この問題は構造的に起きなくなります。
> ただし共同開発者にgit操作が必要になるため、いまは見送っています。

## 💾 バックアップの仕組み（2段構え）

### 1️⃣ `保存.bat` — セーブポイントを作る（git）

作業がひと区切りついたらダブルクリック。
「何をした？」と聞かれるので一言書きます（空欄でもOK）。

その時点の**ファイル全部**が記録され、あとから何度でもその状態に戻せます。
差分だけ記録するので、何百回保存してもフォルダは重くなりません。

**押すタイミングの目安：**

- 🌅 作業を始める前（共同開発者が触ったあとの状態を記録しておく）
- ✅ 何か動くようになったとき
- 🌙 作業を終えるとき
- ⚠️ 大きな変更をする直前

> 💡 迷ったら押してOK。変更が無いときは「変更はありません」と出て何も起きません。

### 2️⃣ `履歴.bat` — 履歴を見る／戻しかたを確認する

いつ何を保存したかの一覧と、昔の状態に戻す手順が表示されます。

### 3️⃣ `バックアップ.bat` — zipで丸ごと退避

`_backups\card-game_20260902-2305.zip` のようなファイルが1つできます。
gitが壊れたときの保険。直近20件だけ自動で残ります。

**押すタイミング：**

- 🔧 大きな作り替えをする前
- 📤 誰かにプロジェクトを渡す前
- ↩️ `git reset --hard` を実行する前（**必須**）

> 💭 なぜフォルダコピーではなくzipなのか
> フォルダコピーだとGoogleドライブが中身を全部同期し直すので重く、
> フォルダ一覧も散らかります。zipなら1ファイルなので軽い。

## ↩️ 壊れたときの戻しかた

### 一番かんたん：GitHub Desktop を使う

GitHub Desktop でこのフォルダを `Add existing repository` で追加すると、
**履歴も変更差分も全部GUIで見られます。** コマンドを覚える必要はありません。

### コマンドでやる場合

`履歴.bat` で表示される7文字のハッシュを使います。

```
git show <ハッシュ>:ファイル名          # 中身だけ見る（戻さない）
git checkout <ハッシュ> -- ファイル名    # ファイル1つだけ戻す
git reset --hard <ハッシュ>             # 全部まるごと戻す（今の変更は消える）
```

⚠️ 3つ目は取り返しがつきません。**先に `バックアップ.bat` を実行してから**。

## 🧰 このPCの環境メモ

移行やトラブル対応のときに必要な情報。

| 項目 | 内容 |
|---|---|
| Python | **3.9.13（Anaconda）**。`python` ではなく **`py -3`** を使う（`python` はWindowsストアのダミーに繋がる） |
| 依存ライブラリ | **Flask のみ** |
| git | **単体では未インストール**。GitHub Desktop 同梱のものを使用。`tools\_git.ps1` が自動で探す |
| 文字コード | 全ファイル **UTF-8** |
| ⚠️ `.ps1` の保存 | **必ず UTF-8(BOM付き)**。Windows PowerShell 5.1 はBOM無しUTF-8を日本語Windowsの文字コードとして読むため、日本語コメントが構文エラーになる（一度これで踏み抜いた） |
