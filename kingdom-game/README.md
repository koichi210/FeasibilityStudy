# ⚔️ 陣形と城壁（仮）

漫画「キングダム」の合戦にインスパイアされた、陣形バトル＋攻城戦の戦術シミュレーション。
ブラウザだけで遊べる、ビルド不要のミニゲーム。

## 🚀 遊びかた

**`index.html` をダブルクリック** するだけ。ブラウザが開いて即プレイできる。
サーバーもインストールも不要（完全にブラウザ内で完結）。

クリア状況はブラウザの保存領域（localStorage）に自動保存される。
別のブラウザ／別のPCで開くと、セーブは引き継がれない点に注意。

## 🎮 できること

タイトル画面から3つのモードを選べる。

- **はじめる（中華編）**: 「野戦」「攻城戦」のステージを順にプレイ。キャラクターはすべてオリジナル
- **歴史編（日本合戦史）**: 河越城の戦い・桶狭間の戦い・川中島の戦い・姉川の戦い・三方ヶ原の戦い・長篠の戦い・賤ヶ岳の戦い・小牧長久手の戦い・小田原征伐・関ヶ原の戦いを年代順に収録。開戦前に短い解説が読める
- **国盗り編（戦国日本）**: 尾張を本拠地に、全国20カ国を「交渉」か「制圧」で従えて天下統一を目指す地図モード。制圧は既存の陣形バトルで決着をつける

共通の戦闘ルール:
- コストを使ってユニット（歩兵・弓兵・騎兵・戟兵）を配置し、CPU軍と戦う
- 兵種の三すくみ＋地形補正（丘・森・河川）を読んで陣形を組む
- 攻城戦では衝車・雲梯で城門・城壁を攻め落とす
- ステージクリアで次のステージが解放される（中華編・歴史編はそれぞれ独立して進行）

## 💾 作業の保存について

- **保存.bat** … ダブルクリックでその時点の状態をgitに記録（コミット）
- **バックアップ.bat** … `_backups/` フォルダにzipのスナップショットを作る
- **履歴.bat** … 過去の保存履歴を見る・戻し方を確認する

Google Drive 上のフォルダなので、これ自体が自動でクラウド同期される。

## 🙅 キャラクター名について

**中華編・国盗り編（の兵種）**の武将・地名の名前は**すべてオリジナル**。原作のキャラ名
（信・王騎 等）に書き換えて自分だけで遊ぶ分には問題ないが、**他の人に共有・公開するときは
オリジナル名のまま**にしておくのが無難（著作権への配慮）。

**歴史編・国盗り編の国名**は、桶狭間・川中島などの実在の合戦や、尾張・美濃といった実在の
令制国名、織田信長などの実在の人物名を使っている。これらは史実であり著作権の対象では
ないため、そのまま使って問題ない。
