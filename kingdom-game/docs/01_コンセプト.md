# 🎯 コンセプト

## これは何？

漫画「キングダム」の合戦シーンにインスパイアされた、**陣形バトル＋攻城戦の戦術シミュレーション**。
ブラウザだけで遊べる、ビルド不要の1プロジェクト。

キャラクター名・地名はすべてオリジナル（詳しくは [README.md](../README.md) 参照）。

---

## 🎮 遊びの中心

### 野戦：兵種の三すくみ＋地形

グリッド上に自軍ユニットを配置し、CPU軍と戦う。

```
歩兵 → 騎兵 → 弓兵 → 歩兵
```

に加えて、丘（防御UP）・森（弓の射程UP）・河川（移動コストUP）などの地形補正が絡む。
「強いユニットを並べれば勝てる」ではなく、**相性と地形を読んで配置する**のがこのゲームの核。

### 攻城戦：城壁と城門を崩す

野戦と同じ盤面ロジックの上に、攻城戦専用のルールを乗せる。

- 攻撃側は衝車（城門破壊）・雲梯（城壁を登る）を運用
- 守備側（CPU）は矢櫓から範囲攻撃
- 城門 or 城壁の一定区画を突破すれば勝利

野戦で鍛えた「配置と相性の勘」が、そのまま攻城戦でも活きるように設計する。

## 🔄 ゲームの流れ

```
🗺️ ステージ選択
     ↓
🪖 配置フェーズ（コストを使ってユニットを出す）
     ↓
⚔️ 行動フェーズ（移動・攻撃・スキル）
     ↓
🤖 CPUの行動
     ↓
💥 戦闘解決（相性・地形補正を適用）
     ↓
🏆 勝敗判定（配置フェーズに戻るor終了）
```

## 🌏 歴史編・国盗り編

中華編と同じ戦闘エンジンの上に、日本の戦国時代を題材にした2モードを追加している。

- **歴史編**: 桶狭間・川中島など実在の合戦を、史実に寄せた布陣で再現。開戦前に短い解説を挟み、
  「なぜその布陣なのか」が伝わるようにする
- **国盗り編**: slime-nationの国造りに近い、地図上で隣接国を交渉/制圧で従えていくモード。
  制圧は動的に生成した合戦ステージを既存の戦闘エンジンでそのまま戦う

どちらも新しい戦闘ルールは増やさず、既存の兵種・三すくみ・地形をそのまま使う。増えるのは
「どのステージを、どんな文脈で見せるか」という層だけ。

## 🖥️ ゴール

1. **PoC（いまここ）** … 野戦ステージ1つ＋攻城戦ステージ1つを、1人 vs CPU でブラウザで遊べる状態
2. **キャンペーン拡張** … 原作の名場面に相当するステージを増やし、クリア状況を保存
3. **対戦拡張** … 将来的にオンライン対戦（盤面ロジックをUIから分離しておき、拡張しやすくする）
