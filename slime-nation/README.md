# 🟢 スライム建国記

小さなスライムが目覚めた森を拠点に、世界地図の領地を「交渉」か「制圧」で従えていく国造りシミュレーション。ブラウザだけで遊べる1枚のWebページ。

## 🚀 遊びかた

**`index.html` をダブルクリック** するだけ。ブラウザが開いて即プレイできる。
サーバーもインストールも不要（Flaskは使っていない、完全にブラウザ内で完結）。

進捗はブラウザの保存領域（localStorage）に自動保存される。
別のブラウザ／別のPCで開くと、セーブは引き継がれない点に注意。

## 🎮 できること

- 世界地図上の隣接する領地を「交渉で迎え入れる」か「制圧して従える」で自国化
- 本拠地の施設（庁舎・農場・工房・魔導書庫・訓練場）を強化して国力アップ
- 仲間（4人）は名前を自由に書き換え可能・鍛えて成長させられる
- 「次の日へ」でターンを進めると資源が増え、たまにランダムイベントが発生
- 経験値が貯まるとリムル役の存在が進化して全体が強化される

## 🙅 キャラクター名について

登場する仲間・領地の名前はすべてオリジナル。作中のキャラ名（リムル 等）に
書き換えて自分だけで遊ぶ分には問題ないが、**他の人に共有・公開するときは
オリジナル名に戻しておくのが無難**（詳しくは Claude との会話ログ参照）。
